## 1. What exists (verified)

### Engine (solid foundation)
- Event-sourced engine: 52-card deck + jokers, deterministic seeded shuffle, zones with visibility (public/private/hidden), turn flow, `foldEvents`, selectors. Framework-free in `src/engine/`.
- 87 jest tests green, typecheck, lint, expo-doctor 20/20.
- Rules layer (`src/engine/rules.ts`): **blackjack** (TWIST/STICK/STAND, dealer auto-plays to 17, bust/winner calc, soft aces, virtual house seat) and **poker shell** (BURN/FLOP/TURN/RIVER/SHOWDOWN, FOLD/CHECK/CALL/RAISE, 5-of-7 evaluator with numeric tiebreaks). Rules are pure, emit primitive events.
- Presets: Freeplay, Deal 2 each, Blackjack, Poker. Solo blackjack with HAND OVER banner + Next hand.
- `sessionHistoryStore` (session history), `customPresets.ts` manifest scaffold.

### Multiplayer
- Relay live (relay.roxai.click): rooms, 6-char join codes, host auth HMAC, TTL sweep, reconnect with seat/room grace, recipient-filtered broadcast (no hidden-card leaks), direct addressing.
- Proven: two-client live run, online blackjack E2E (guest TWIST via `game_action`), reconnect E2E 5/5.

### UI / visuals (partial, mixed quality)
- Table world: ivory/crimson/ink tokens, felt radial glow + weave hairlines, paper grain, TableSurface shared by hub + table.
- Cards: branded backs (ivory/Noir/Crimson), court cards (Dealer J / Host Q / Master K custom SVG), corner indices, French pip field, FlipCard.
- Nav: chips on table edge + deck-object Deal anchor (directive 13).
- Setup: fanned recipe cards on felt, player chips, option tokens (directive 14).
- Presets page: fanned recipe cards, DEFAULT stamp, duplicate/edit/delete (directive 5).
- Lobby: landing / create / join / room screens, code copy, player list.
- Store: cosmetics (backs/themes) + pass cards, preview-mode unlocks.
- Home: hero CTA, store preview carousel, Master tile, sale row.
- Motion: surface morph (home↔hub), felt-sweep transition, deal stagger, press feedback, FlipCard. `lib/motion.ts` haptics.
- Offline PWA: service worker, immutable asset caching, offline cold-launch proven.
- expo-audio installed but **unused** (no sound in the app).

## 3. What should exist (the target)

### 3.1 Gameplay library
Every game = a **recipe** (data, not code) executed by the engine. `executeRecipe` replaces `Preset.setup()`.

**Free library (v1):**
1. Freeplay (exists — keep as the blank deck)
2. Deal 2 each (exists — give it an objective/win state or fold into freeplay variants)
3. Blackjack (exists, full rules — add score across hands, rules view, dealer toggle)
4. Texas Hold'em (upgrade the poker shell: blinds, betting chips, pot, showdown flow, winner announce)
5. War (2p, flip-compare, quick rounds)
6. Go Fish (2-6, ask/collect, needs `card/ask` engine addition)
7. Old Maid (2-8, joker = maid, pair-and-pass, natural pass-and-play)
8. Crazy Eights (2-7, match suit/rank, eights wild, needs `matchRule` validation)
9. Sevens / Fan Tan (3-8, shedding around the 7s)

**Solo pillar (first-class, Josh 2026-08-11):**
10. Solo blackjack (exists — polish + score across hands)
11. Klondike (draw 1 / draw 3 toggle)
12. FreeCell (classic, skill-based)
13. Pyramid (pair-to-13, quick rounds)
14. Golf (flip-and-match, short rounds)
Shared draw/flip engine, one layout per game, same table world + animation quality, offline-capable (PWA proven). Solo ships WITH the free library, not after it.

Every game needs: **rules view** (one tap, plain English), **win/lose state** with winner + celebration, **replay** (same players, fresh deal), **score tracking** across rounds where the game has rounds.

### 3.2 Gameplay depth
- In-game scoreboard / round tracking (blackjack: hands won; poker: chip counts; library games: rounds won).
- End-of-game state for EVERY game (freeplay gets a graceful "session over" too).
- Auto-reshuffle when draw pile empties (exists as config, verify + surface in UI).
- Hand sort (rank/suit) toggle for freeplay.
- Undo last action (event-sourced engine makes this cheap — replay events minus one).
- Turn indicator polish: whose turn, what they can do, why (hint text).
- Rules/help: accessible from hub AND table, per-recipe.

### 3.3 Animation (the "suck" fix)
- **Deal**: cards fly from the deck object to hands with stagger + 1-2px settle spring (exists partially, needs the deck-object origin and landing settle).
- **Move**: draw slide, discard slide + rotate, play lift + land (currently instant).
- **Flip**: FlipCard exists, keep; ensure it's used for all reveals.
- **Pass ritual**: veil slide + seal expand on reveal (planned, not built).
- **Win celebration**: simple confetti / card burst / mascot moment.
- **Nav**: chips deal-in stagger (exists), deck object press animation (deal-like).
- **Home**: the deal moment — deck object on felt, tap → cards fly (the hero becomes the table).
- Reduced-motion safe everywhere. 60fps at 375px. No layout jitter.

### 3.4 Transitions / continuity
- ONE continuous table space: home → setup → table → lobby → pass all feel like the same felt, objects move, nothing "loads".
- Surface morph extended to hub→table (deal lands you in play without a page swap), lobby→table, store/profile as drawers or felt overlays, not pages.
- No page-pop anywhere. Every screen change is a motion, not a swap.

### 3.5 Home screen (the "weak & lackluster" fix)
- Home IS the table: felt surface, deck object center-bottom (the Deal), chips for nav, small "continue session" state if one exists, quick re-entry to last game.
- The marketing bits (store preview, Master tile, sale row) either integrate as table objects or move to the store screen. Kill the fake sale row.
- First-run: one-line "Tap the deck to deal" affordance; onboarding hint on first launch.

### 3.6 UX completeness
- Empty states: table (no session), lobby (no room), store (no items), presets (no custom).
- Session resume: mid-game leave → "GAME IN PROGRESS / Resume" (exists partially, polish).
- Confirm on destructive: end session, leave lobby.
- Player naming/avatars: name entry at deal time (exists in lobby; pass-and-play needs it at setup).
- Sound: wire expo-audio (installed, unused): deal, flip, discard, win. Mute toggle in settings. Default on, subtle.
- Safe areas, 44px+ targets, 375px clean, desktop web clean. No native select, no default browser controls.

### 3.7 Multiplayer completeness
- Hold'em playable end-to-end by guests (bet actions exist; street progression is host-only by design — decide whether guests may advance streets).
- Live 2-device proof for blackjack AND hold'em post-changes.
- Leave/close flows with confirmation; host leaving ends room with notice.
- Guest sees recipe name + rules view in lobby.

## 4. The "ready" bar (definition of done)

Deckd v1 is **gameplay-ready** when ALL of these pass. This is the benchmark Luna builds against and the QA gate before anything else happens.

### Gates

**G1 — Library:** Freeplay, Deal 2, Blackjack, Hold'em, War, Go Fish, Old Maid, Crazy Eights, Sevens + solo blackjack + Klondike all playable from setup to win/lose. Each has: rules view, winner/end state, replay, score where rounds exist.

**G2 — Playability:** every game completes a full turn cycle without confusion at 375px AND desktop. Turn indicator, action bar, and hints always match the rules. No dead buttons. No silent no-ops (the poker-communal bug class is gone for every game). Undo exists for freeplay-family games.

**G3 — Animation:** deal, move, flip, discard, pass ritual, win celebration all animated with settle physics. Reduced-motion = plain fades. No jitter, no clipping at 375px. Deck object is the deal.

**G4 — Continuity:** home → setup → table → pass is one felt space. No page pops. Home is the table with the deck as the hero action.

**G5 — UX:** empty states, resume, confirm-on-destroy, player names, hand sort, sound with mute, safe areas, 44px targets, no console errors. First-run hint present.

**G6 — Solo:** solo blackjack + Klondike + FreeCell fully playable offline (cold launch from cache), same visual/animation quality as multiplayer surfaces.

**G7 — Multiplayer:** blackjack + hold'em lobbies: host deals, guests act, reconnect works, no hand leaks. Proven by live 2-client E2E after the final build.

**G8 — Quality:** all jest suites green (expanded per new game), typecheck, lint, expo-doctor, live QA scripts pass, fresh visual check at 375×812 and 1440×900.

**G9 — Monetisation (parked, NOT part of this bar):** store products, keys, submission. Preview mode stays.

## 5. Luna dispatch plan (build order)

Each slice: typecheck, lint, jest, expo-doctor, deploy preview, verify 375px. Commit per slice.

1. **Recipe schema** (engine): `executeRecipe`, migrate 4 presets, all 87 tests stay green. The unlock — everything else builds on it.
2. **Free library v1**: War, Go Fish, Old Maid (engine additions: `card/ask`, pair logic).
3. **Free library v2**: Crazy Eights (`matchRule`), Sevens.
4. **Rules + help + win states**: per-recipe rules view, end-of-game flows, scoreboard, replay for every shipped game.
5. **Hold'em completeness**: blinds, chips, pot, guest street control, showdown winner flow.
6. **Animation pass**: card moves (draw/discard/play), deal from deck object + settle, pass ritual, win celebration.
7. **Continuity pass**: surface morph hub→table, lobby→table, home-as-table redesign, drawer screens for store/profile.
8. **Solo pillar**: Klondike + FreeCell + Pyramid (shared engine, offline).
9. **UX pass**: empty states, undo, confirm, hand sort, sound (expo-audio), first-run hints, turn indicator polish.
10. **Multiplayer E2E**: live 2-device blackjack + hold'em proof, reconnect, privacy. Final gates G1-G8 verification.

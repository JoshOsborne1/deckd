# Deckd deep audit + cleanup plan — 2026-09-03

Method: fresh eyes on the live build (https://deckd-app.roxai.click, entry-f7e67639, exported 2026-08-23), screenshots taken today at 1512px and 375px widths (home, hub, store), the Aug-15 sweep shots for game tables, full code read of engine/stores/layers, gates run today. No fixes applied, no files touched except this doc.

Gates today: `typecheck` clean, `lint` 0 errors / 12 warnings, `jest` 324/324 (one worker-teardown warning, harmless). The engine is green. Everything below is about what green tests don't catch.

## Verdict

The foundation is genuinely good: event-sourced engine, seeded deterministic deals, recipient-filtered multiplayer projections, 324 passing tests, clean typecheck. That work survives.

The surfaces are the mess Josh keeps seeing. Three root diseases cause ~80% of it:

1. **No single card-face system.** Three generations layered on top of each other (lucide pips, custom courts, RevK SVG strings) with the newest one (RevK, `lib/revkCards.ts`) shipped distorted (`preserveAspectRatio="none"`) and unrecolored (raw `red`/`black` fills, `#fffdf8` stock instead of the `cardPaper` token). Every table renders a slightly different deck.
2. **Layout is tuned for no viewport.** Desktop-width renders a 300px phone column (home) or a left-anchored column with 900px of void (store). At 375px the nav fan clips off the left edge and overlaps content. Nobody has done a pass where each surface is laid out deliberately at 375 AND at desktop.
3. **Copy was never edited.** Tutorial fragments ("THE DECK IS THE DOOR", "PICK A RECIPE AFTER THE DEAL"), duplicated readouts (POT twice, STACK twice, STOCK twice), dangling prepositions ("PASS DEVICE TO"), negative durations ("-24h", "-Lifetime"). Reads as placeholder text that shipped.

Do not add features until the visual system is fixed. The cleanup below is ordered so each slice is verifiable with a screenshot diff.

## 1. Visual findings

### 1.1 Cross-cutting (every surface)

- **Dead vertical band on every table.** Top cluster (opponents/scores) + bottom cluster (hand/actions) with 120–600px of empty felt between. Worst: Golf (~55% of screen height unused), Poker (~130px void above nav), store recipe section trailing into nothing.
- **Dashed placeholder boxes everywhere.** DISCARD / WASTE / COMMUNITY render as wireframe stubs (light-gray dashed stroke on cream, often sub-AA contrast), not felt furniture. Fix once with a real inset-well component, every table heals.
- **Duplicated readouts.** Poker: POT + STACK in the stat strip AND in a red pill below the cards; STOCK 17 in the header AND as a badge on the deck (Golf). One source of truth per number, displayed once.
- **Unlabeled icon buttons.** Every table has a row of 4 thin-outline utility icons (shuffle/history/rules/flag) with no labels next to solid red action pills. Two visual weights, zero affordance. Label them or move them into the UtilityDrawer.
- **Gray-on-cream fails contrast.** `#8C857A`-ish body copy on `#F8F5EE` is ~3:1. Fails AA at 15px, worse at 10–11px divider labels, stats, "WITH FRIENDS". Darken `inkMuted` or lighten usage. This is an App Review / accessibility flag, not taste.
- **Four reds, one pink, no system.** Brand `#B02020`, hot `#E5322F`, maroon avatar `#7A2424`-ish, pink RULES pill `#F4DBD7` (used exactly once). The pink pill must die; avatar must use a brand red.
- **Paper grain reads as dirt.** `lib/paperGrain.ts` (360 deterministic fibres) is a good idea, but at current opacity/scale screenshots show uneven speckle blotches and a visible horizontal seam across the home ellipse. Reduce opacity ~50%, verify at 2x, mask decorative shapes to their containers (the home ellipse bleeds past the panel bottom edge behind the nav).
- **Radius/shadow/casing anarchy.** 24px panel vs 18px Home square vs 12px pills vs full-round pills vs tilted cards; muddy inconsistent drop shadows; ALL CAPS + Sentence + Title case within 400px. Lock the `radii`/`shadow` tokens and delete the one-offs.

## 2. Code findings

### 2.1 P0 — correctness/visual bugs in source

1. **RevK faces render distorted and off-palette** (`lib/revkCards.ts`, `lib/cardJokers.ts`, `components/CardFaceArtwork.tsx`). Every SVG string carries `preserveAspectRatio="none"` (non-uniform scale = the X-blob 5♦ and stray edge pips in screenshots) with raw `fill="red"` / `fill="black"` and `#fffdf8` stock. The deckd palette (warm crimson family, warm ink, `cardPaper`) was never applied. Fix: `xMidYMid meet`, recolor transform red→brand scale / black→ink at import time, stock→`cardPaper`. One fix heals every table. Success signal: 5♦/6♦/10 render clean at xs/sm/md/lg in CardLab, screenshot diff.
2. **Center nav slot renders two different broken states** (bare logo on home, blank card + floating D on store). Find the route/morph-dependent branch in `GlobalNavBar.tsx` (577 lines) and make the Table card unconditional per directive 20.
3. **Nav fan wider than 375px** (clipped Home card, content overlap). Add rect-assertions to `qa/deckd-nav5-qa.cjs`: all five slots within [8, 367], no overlap with content above `NAV_BAR_RESERVE`.
4. **`PlayingCard` xs (16×22) is decorative-only but used for live content?** Audit callers; anything tappable at 16px is a violation. Minimum tappable face is sm (60×84).
5. **`Image resizeMode="stretch"` on card backs** (`PlayingCard.tsx:70`) — non-uniform scale on the branded backs. Use `cover` (backs are already 2.5:3.5).
6. **`HomeLayer.RECIPE_LABELS` covers 5 of 13 presets.** Missing ids fall through to naive capitalization: "blackjack"→"Blackjack" (should be "Blackjack-style"), "freecell"→"Freecell" (should be "FreeCell"), "poker"→"Poker". Derive display names from the preset (`preset.name`) instead of a hand map.

### 2.2 P1 — architecture debt

7. **God components.** HubLayer 1661, TableLayer 1369, SolitaireBoard 1004, PokerTable 846, SevensTable 818, BlackjackTable 754, rules.ts 1943. The three worst (Hub/Table/rules) own most churn (TableLayer 42 commits, Hub 28). Split by extraction, not rewrite: HubLayer → RecipeFan / PlayerSetup / DealDock; TableLayer → generic surface + OldMaidTable extraction (kills the `isContextualGame` special-casing); rules.ts → one module per game behind the existing `GameRules` interface. Success signal per extraction: gates green + identical QA screenshots.
8. **All layers mounted, hidden ones hit-testable.** `app/index.tsx` keeps home/hub/table/lobby/pass in the DOM; opacity-0 layers still intercept taps and pollute the AX tree (documented pitfall, still biting: QA needs `elementFromPoint` probes, `force:true` flags). Fix for real: `pointerEvents="none"` + `accessibilityElementsHidden`/`importantForAccessibility="no-hide-descendants"` on inactive layers, or unmount off-morph-zone layers (morph progress already tracked). This kills a whole class of phantom QA failures and real mis-taps.
9. **Broad zustand subscriptions re-render everything per event.** `useGameStore((s) => s.state)` in HomeLayer and elsewhere re-renders on every engine event. Select slices (`state.phase`, `state.players.length`, memo'd selectors exist already) — apply them at the 5 hottest components. Verify with a render-count probe, not feel.
10. **`SvgXml` parses 52 full SVG documents per render path.** `lib/revkCards.ts` is 580KB of duplicated `<defs>` per card. Pre-parse once (module-level cache keyed by card id) and memo `CardFaceArtwork`. Bundle today is 5.9MB for a card game; this plus `app-serve/` in git (next) is why.
11. **Card-back PNGs ship at unknown weight through `stretch`.** Check `assets/card-back-*.png` dimensions; downscale to 2x display size max, convert to WebP if Expo web serves it cleanly.

### 2.3 P2 — hygiene

12. **Deploy output is committed to git.** `app-serve/` (5.9MB bundle + hashed assets + per-route HTML, 26+ commits each) is tracked. Add `app-serve/` to `.gitignore` (keep `serve.mjs` + a BUILD note), `git rm -r --cached app-serve`, deploy from CI/export only. Repo shrinks massively; stops the "which bundle is live" confusion (PM2 serves the main checkout's `app-serve/`, a known footgun).
13. **39 QA scripts with overlapping coverage.** `qa/` has nav5 ×5 scripts, sweep + visual-qa + new-batch + per-game scripts, most asserting the same geometry invariants. Consolidate to: `sweep` (screenshots), `invariants` (overflow/errors/nav-rects/pass-veil per surface), per-game *interaction* scripts only. Delete the rest. Success signal: same assertions, one command, half the runtime.
14. **Dead-end files.** `app/lab.tsx` is 6 lines (route stub for CardLab work — keep or cut); `components/CardCourt.tsx` vs RevK courts (two court systems? verify, delete one); `lib/bleProtocol.ts` kept as "wire-framing reference" (it's 2026, BLE is dropped — archive it); `vendor/` is 17MB vendored but only RevK is wired (hayeah/notpeter unported per directive 12 — decide: port or delete).
15. **Lint warnings (12) are all real.** Unused vars in engine tests (`fishBefore`, `sevensBefore`), unused `applyEvent` import. Zero them; warnings are where the next bug hides.
16. **Jest worker-teardown warning.** Something leaks timers/handles (relay transport heartbeat is the prime suspect). `--detectOpenHandles`, fix, silence.
17. **PM2 `deckd-app` shows 748 restarts** (siblings similar). For a static file server that's either deploy churn or a crash loop. Check `pm2 logs deckd-app --lines 50` timestamps; if crash-looping, fix the server instead of restarting it.
18. **No `CURRENT.md`.** Global ops rule requires one live brief per project; this repo runs on `STATUS.md` + `LOOP_DIRECTIVES.md` + `AGENTS.md` and the canonical-state check fails. Either adopt `CURRENT.md` (one page: what Deckd is, what's live, what's next) or record why this repo is exempt.

## 3. Optimizations (measured, not vibes)

- **Bundle: 5.9MB `entry-*.js`.** Biggest wins in order: dedupe RevK defs (580KB source, repeated per card), audit `lucide-react-native` import style (named imports from the package root can defeat tree-shaking — verify the bundle, import from per-icon paths if needed), confirm `react-native-purchases` lazy-import actually splits (it was the P0-1 suspect; verify it's out of the web bundle, not just deferred). Target: under 3MB. Measure with `npx expo export --platform web` + `ls -la`, plus a `source-map-explorer` or manual chunk scan if available.
- **Render: subscription narrowing (2.2.9) + `CardFaceArtwork` memo + pre-parsed SVG cache.** Measure: render counts during a Crazy Eights turn (deal→play→pass) before/after. No profiling, no claim.
- **State growth: event log is unbounded in memory + persisted.** Long sessions (Golf, FreeCell) accumulate hundreds of events; `foldEvents` replays all on load. Add log compaction (snapshot + tail already exists in `syncLogic` — use it locally too) or cap persisted history. Measure load time at 500+ events.
- **Images: `resizeMode="stretch"` → `cover`;** downscale backs; re-encode sounds (68KB total, fine, skip).
- **Metro/dev:** the `.expo/` + metro-cache wipe dance after dep swaps is documented but manual. Script it (`npm run fix:metro`) so the next person doesn't rediscover it.

## 5. Bad decisions (name them so they don't recur)

1. **Five nav designs in 25 days** (cards → rail → chips → standing cards, directives 6/11/13/20 + v5). Each rejected wholesale, each rebuilt from scratch. The fan metaphor was never prototyped cheaply (a static mock would have killed chips-in-felt in an hour). New rule: nav changes ship as a screenshot mock first, Josh picks, then code. No more animated redesigns of unapproved layouts.
2. **All-layers-mounted architecture.** Every surface in the DOM, hidden ones hit-testing and polluting AX. It has cost more in QA workarounds (`elementFromPoint` probes, `force:true` autopsies, stale-harness misdiagnoses) than unmounting ever would. Fix in 2.2.8.
3. **Deploy output in git.** `app-serve/` tracked with the 5.9MB bundle. Every deploy doubles as a repo-bloat commit and enables the worktree-serve footgun. Fix in 2.3.12.
4. **39 QA scripts instead of one harness with 39 assertions.** Coverage grew by accretion; overlapping scripts encode stale expectations (the blinds-era holdem harness misdiagnosis is documented). Consolidate per 2.3.13, and every harness gets a "stale-expectation" header: engine behavior it assumes + date.
5. **Three card-face generations, none removed.** Lucide pips → custom courts → RevK strings coexist. The style-mixing disease (Aug-15 root cause #1) is a direct consequence. One deck component, delete the ancestors.
6. **Preset maxPlayers lies.** Freeplay declares 12, deal-2 declares 10; hub silently clamps to 6 (the real product rule: 2–6 pass-and-play). Set honest numbers; silent clamps are bugs with good intentions.
7. **Hand-rolled label maps instead of preset data** (`RECIPE_LABELS`, hub copy, store copy each re-describe the same games). Display names, ranges, one-liners live in exactly one place: the preset. Everything else derives.
8. **Monetization UI built before gameplay was right** (directive 15 said gameplay first; the store still shows prices for unbuyable passes). Parked is parked: either hide prices or label the store preview honestly.
9. **The autonomous loop machinery outgrew the project** (watchdogs, lanes, merge-deploy, 11 worktrees, 42 commits on 2026-08-12 alone) and was shut down by Josh. The lesson stuck (native `/loop` now), but `docs/` still carries LOOP_* design docs as live weight. Archive `LOOP_RUNBOOK.md`, `LOOP-SYSTEM-DESIGN.md`, `LOOP_PLAN.md` under `_archive/` with SUPERSEDED headers — they're history, not spec.
10. **Directives accrete, never retire.** `LOOP_DIRECTIVES.md` has 21 directives, several mutually superseding (6→11→13→20). It worked as a log, but as a brief it's a maze. Rewrite as: current intent (1 page) + changelog. Same for `STATUS.md` (30KB history log; keep last month, archive the rest).
